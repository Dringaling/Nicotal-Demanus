# Lọc theme theo tag

- Sidebar trang "Tạo" có thêm khối Theme Tags: tìm tag, chọn nhiều tag và
  chọn/bỏ chọn tất cả giống khối Tags.
- Danh sách theme trong ô Template được lọc theo tag đã chọn; theme đang dùng
  vẫn được giữ trong danh sách để không mất lựa chọn.
- Lọc hết theme thì ô Template hiện dòng "Không có theme khớp tag" thay vì
  danh sách rỗng.
- Tìm kiếm input và chọn tag input không làm mất tag theme đang chọn (và ngược
  lại).
