# Cấu hình AI ngay trong app

- Nút "CẤU HÌNH AI" ở góc dưới trái mở bảng sửa nhà cung cấp, model, API key và
  chọn model mặc định, không phải sửa file cấu hình bằng tay.
- Thay đổi có hiệu lực ngay, không cần khởi động lại app.
- Cấu hình người dùng nằm trong `config/providers.local.toml` (không commit);
  API key chỉ nằm trong `secret/` trên máy đang chạy.
- Chỉ máy đang chạy app mới sửa được cấu hình; máy khác trong mạng chỉ xem.
- Xoá được nhà cung cấp/model tự tạo; cấu hình phát hành sẵn chỉ bị ghi đè.
