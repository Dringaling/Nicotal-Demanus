# Lưu theme

Trang Theme Edit cho sửa trực tiếp nội dung TOML của theme đang chọn.

- Bấm `Lưu` để ghi vào bản đang dùng; theme hệ thống vẫn giữ bản gốc để reset.
- File phải có `[theme]`, `[palette]`, `[colors.*]`, `[typography]` và
  `[layouts.three_cards.header]`, nếu thiếu sẽ báo lỗi và không ghi.
- Lưu TOML sẽ mất comment trong file.
