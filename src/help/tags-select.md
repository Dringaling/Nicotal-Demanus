# Chọn tất cả

Nút có icon chọn nhiều (nền xanh) chọn toàn bộ tag **đang hiện** sau khi tìm.

- Nút chỉ hiện khi bạn đang tìm tag và còn tag chưa chọn.
- Sau khi chọn, trang tự áp dụng bộ lọc: input hiện ra là input có **bất kỳ**
  tag nào trong số đã chọn.
- Bỏ tìm kiếm rồi chọn từng tag vẫn cho kết quả tương tự.
